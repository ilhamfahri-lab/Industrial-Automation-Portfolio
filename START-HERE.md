# Start Here

This is a ready-to-fill engineering portfolio scaffold. It does not claim the five projects have been implemented.

## First steps
1. Read the root README and the portfolio roadmap.
2. Start with Project 01; confirm that TIA Portal V18, the intended PLCSIM version, Factory I/O, and WinCC can launch and that the required licenses are available.
3. Build a small working PLC sequence before adding advanced SCADA integrations.
4. Replace TBD values with actual design choices, or mark them as not implemented.
5. Add only real screenshots, test logs, and demonstrable results.

## Before making the repository public
- Review the license and copyright choice.
- Check for credentials, proprietary files, and personal information.
- Run and record the listed tests.
- Replace all project statuses with accurate states.
- Confirm that linked files exist and that the project can be understood without private access to your laptop.
