# PLC-001 — Automated Conveyor Control System

## Project Overview
A software-only industrial automation project that demonstrates PLC sequence control for a conveyor handling station.

The project is intentionally scoped for a student/fresh-graduate portfolio: clear engineering documentation, deterministic control logic, fault handling, simulation, and test evidence without claiming physical hardware implementation or plant commissioning.

## Engineering Workflow
**Problem → Requirements → System Design → Control Logic → PLC Implementation → Simulation → Testing → Results → Portfolio Evidence**

## Scope
- Conveyor start/stop sequence
- Product detection and transfer logic
- Sensor/actuator state handling
- Interlocks and permissives
- Fault and emergency-stop behavior
- PLC-oriented implementation
- Software/simulation-based functional and fault testing

## Out of Scope
- Physical PLC commissioning
- Real I/O wiring
- Real motor/inverter commissioning
- Plant operation claims
- Measured field performance

## Repository Structure
