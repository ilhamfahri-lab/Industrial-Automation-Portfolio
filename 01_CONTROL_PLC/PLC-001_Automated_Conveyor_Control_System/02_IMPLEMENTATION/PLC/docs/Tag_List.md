# PLC Tag List

| Tag | Type | Description |
|---|---|---|
| StartCmd | BOOL | Start command |
| StopCmd | BOOL | Stop command |
| EStopHealthy | BOOL | Emergency stop healthy status |
| ProductDetected | BOOL | Product detection input |
| CriticalFault | BOOL | Critical fault status |
| ResetCmd | BOOL | Fault reset command |
| MotorRun | BOOL | Conveyor run command |
| FaultAlarm | BOOL | Fault alarm output |
