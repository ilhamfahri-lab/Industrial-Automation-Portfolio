## Design principles
1. **One repo, five separate projects.** Shared standards live in docs; project-specific artifacts stay in each project folder.
2. **Evidence before claims.** Keep test results and demo media tied to specific tests.
3. **Simulation is labeled honestly.** Do not claim physical validation, safety certification, or real commissioning unless it actually happened.
4. **Toolchain is not the portfolio.** Reviewers should see the engineering problem, design decisions, test method, and results—not just screenshots of software.
5. **Keep it safe to publish.** No credentials, license keys, confidential plant files, or employer/client information.

Primary documentation is in English for international applications. See each project README for navigation and its current scope.
