# File Naming and Evidence Rules

- Use lowercase kebab-case for folders and Markdown files.
- Prefix evidence/test records where sequence matters: EV-001, TC-001.
- Use dates in ISO format: YYYY-MM-DD.
- Prefer SVG for simple diagrams, PNG for screenshots, and retain editable diagram sources.
- Captions should state what the evidence proves.
- Store native project exports in the relevant project folder only if redistribution is permitted.
- Before committing vendor project files, check for credentials, machine-specific settings, confidential content, and redistribution restrictions.
- Use Git LFS or another permitted channel for large binaries; do not commit installers, license keys, caches, or local database data directories.

Suggested evidence names: EV-001-normal-operation.png, EV-002-alarm-response.png, EV-003-recovery.png.
