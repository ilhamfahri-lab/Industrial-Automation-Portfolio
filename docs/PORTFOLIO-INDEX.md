## Status definitions
- **Planned:** scope is defined; implementation has not been demonstrated.
- **In progress:** implementation has started; acceptance criteria remain open.
- **Tested in simulation:** the recorded tests passed in the stated simulation environment.
- **Validated on physical equipment:** use only with real, documented tests under appropriate supervision.
- **Archived:** retained for reference, not actively developed.

Change a status only when the evidence supports it.
