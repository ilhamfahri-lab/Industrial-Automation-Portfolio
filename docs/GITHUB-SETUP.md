# GitHub Setup

Recommended repository name: industrial-automation-portfolio

Suggested description: Simulation-based portfolio in PLC/SCADA, instrumentation and control, critical-power monitoring, industrial analytics, and OT networking.

## Publishing from a local copy
1. Extract the ZIP scaffold.
2. Open a terminal in the extracted folder.
3. Run:
   git init
   git add .
   git commit -m "chore: initialize engineering portfolio structure"
4. Connect the folder to the GitHub repository and push to main. If a remote is already configured, inspect it before adding another.
5. Check the root README and all project links in the browser.

If the repository is public, review license/copyright choice and scan every file for confidential details before publishing.
